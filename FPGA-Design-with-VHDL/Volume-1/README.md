# FPGA Design with VHDL – Volume 1

## Official Source Code Repository

Welcome to the official GitHub repository for **FPGA Design with VHDL – Volume 1**, written by **Fatih Ilig**.

This repository contains the VHDL source code examples presented throughout the book, organised by chapter and example number to help you easily find, download, and experiment with each design.

### Repository Structure

Examples are organised using the following naming convention:

- `Chapter_02/Ex_02_01/` — First example in Chapter 2
- `Chapter_03/Ex_03_01/` — First example in Chapter 3
- `Chapter_05/Ex_05_03/` — Third example in Chapter 5

Each example folder contains the corresponding VHDL source code and any supporting files provided for that example.

You are encouraged to open the examples in Vivado, run simulations where appropriate, modify the code, and explore how the designs behave.
