# FPGA Design with VHDL

Welcome to the GitHub repository for **FPGA Design with VHDL**, a three-volume book series designed to guide readers from the fundamentals of VHDL and FPGA design to more advanced digital design techniques.

Each volume builds on the previous one, combining clear explanations with practical examples. This repository is organised into separate folders for each volume, where readers can find the accompanying design files, examples, and supporting materials as they become available.

## The Three Volumes

### Volume 1 — Fundamentals

An introduction to FPGA design and VHDL for beginners. Covers essential FPGA concepts, VHDL syntax and data types, processes, sequential and concurrent statements, loops, simulation, and hands-on examples using AMD Vivado and FPGA development boards.

### Volume 2 — Structured and Reusable Design *(Planned)*

Builds on the fundamentals with hierarchical design, reusable VHDL components, functions, procedures, packages, finite state machines (FSMs), testbenches, memories, and practical design and verification examples.

### Volume 3 — Advanced FPGA Design *(Planned)*

Explores more advanced design techniques, including clock domain crossing (CDC), pipelining, synthesis-aware RTL, FPGA memory resources, timing analysis, constraints, design best practices, and advanced verification.

If you are new to VHDL or FPGA design, start with **Volume 1** and progress through the series in order.
